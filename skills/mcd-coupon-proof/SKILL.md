# 麦券明白账

面向使用 MCP 助手的麦当劳会员，帮助读懂券面价格证据、时间状态及尚未确认的限制。项目不是麦当劳官方产品。

## 先选择检查方式

- 用户要看示例或演示规则：可运行合成数据演示；它不联网、不用 token，也不代表真实账户。
- 用户要求查看自己的账户券包，且当前 MCP 客户端已配置官方凭据：使用已配置的官方 `query-my-coupons` 工具，或在具备 Node.js 的项目环境运行 `node ../../src/cli.mjs audit`。脚本路径相对于本 Skill 所在目录。真实审计只读券包，不领取、不核销、不下单、不消费积分、不支付。
- 用户提供具体门店及用餐方式并要求确认可用范围：可选调用官方 `query-store-coupons`。将其结果描述为该门店和当时条件下的核验结果；没有实际调用及结果时，明确标为未核验。
- 只有用户要求计算具体订单总价时，才考虑 `calculate-price`。不要凭空创建商品、订单或券参数。

不要声称本地示例等同于真实查询，也不要把账户券包查询说成门店适用性验证。MCP 工具名和能力以用户客户端实际配置及官方文档为准；不得虚构工具或调用结果。官方文档入口：[麦当劳 MCP 平台](https://open.mcd.cn/mcp/doc)。

## 解释规则

- 免费、付费判断必须依据官方结构化价格证据，不能由券标题或广告语推断。项目规则只把 `discountInfo.discountDesc === "用券价格"` 的合法金额作为用券价格证据。
- 只有 `ifFreeCoupon === true` 且零元价格证据明确一致时才说明餐品价格为免费；明确正数价格可说明为付费。冲突、字段缺失或不确定时归为未知，并指出缺少或矛盾的证据。
- 免费不等于无条件赠送。列明仍未知的最低消费、渠道、门店、时段或星期限制，不把推测写成事实。
- 以北京时间解释有效期。精确交易起止时间优先于日期；未生效与过期要区分。无效日期、停用或数量为零不能说成当前可用。
- 说明结果来源、检查时间、完整性和未验证项。若查询不完整，保留 `complete=false` 的含义，不把结果描述为完整券包。
- 按规则排序用于阅读，不得称为“最省钱”或金额最大化推荐。

## 隐私与动作限制

只在用户明确要求并已配置官方 MCP 凭据时查询真实账户。不要索取、展示、记录或传送 token、券码、账号、ID、图像 URL 或原始账户响应；不要主动领取、核销、下单、消费积分或支付。具体门店适用性只能基于实际门店查询结果表述，最终以官方 MCP 和结算时的实时信息为准。
